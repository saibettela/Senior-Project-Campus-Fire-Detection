## 🆘 Common Issues & Solutions

### "Kaggle dataset download fails"
```bash
# Make sure kaggle.json is in right place
ls ~/.kaggle/kaggle.json  # Should exist

# Or download manually from browser
# https://www.kaggle.com/datasets/deepcontractor/smoke-detection-dataset
```

### "Python script crashes"
```bash
# Make sure virtual environment is activated
source venv/bin/activate  # You should see (venv) in prompt

# Reinstall dependencies
pip install --upgrade -r requirements.txt
```

### "STM32CubeMX can't import ONNX"
- Check ONNX file isn't corrupted
- Try opset=12 when exporting from Python
- Update X-CUBE-AI to latest version

### "Model predictions are wrong"
- ⚠️ **#1 ISSUE:** Wrong scaler parameters!
- Verify you copied EXACT values from `scaler_parameters.json`
- Double-check units (°C, %, ppb, ppm)
- Test with known fire/no-fire samples
