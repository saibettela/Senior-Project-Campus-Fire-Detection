## 🚀 Quick Start Workflow

### Phase 1: Dataset Preparation 
**Location:** `02_Dataset/`

```bash
cd 02_Dataset/
# Download dataset from Kaggle
# Run data exploration and preprocessing
# Output: scaler_parameters.json (CRITICAL!)
```

### Phase 2: Model Training 
**Location:** `03_Model_Training/`

```bash
cd 03_Model_Training/
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt

# Run training pipeline
python 01_data_exploration.py
python 02_data_preprocessing.py
python 03_train_basic_model.py
python 04_train_temporal_model.py
python 05_export_onnx.py

# Output: fire_detection.onnx, scaler_parameters.json
```

### Phase 3: Model Deployment 
**Location:** `04_Model_Deployment/`

```bash
cd 04_Model_Deployment/
# Copy ONNX model from training
cp ../03_Model_Training/trained_models/fire_detection.onnx .

# Follow INSTRUCTIONS.md to:
# 1. Open STM32CubeMX
# 2. Import ONNX model
# 3. Configure quantization (int8)
# 4. Generate C code
```

### Phase 4: Firmware Integration 
**Location:** `05_Firmware/`

```bash
cd 05_Firmware/
# Copy generated X-CUBE-AI code from deployment
# Integrate with sensor drivers and LoRa communication
# Build and flash to STM32
make
make flash
```

### Phase 5: Testing & Validation 
**Location:** `06_Testing/`

```bash
cd 06_Testing/
# Run controlled fire tests
# Measure performance against DR requirements
# Document results
```

## 📝 Critical Files

### 1. **scaler_parameters.json**
**Location:** `02_Dataset/processed/` AND `05_Firmware/Core/Inc/`

**Why Critical:** Your microcontroller needs the EXACT same min/max values used during training to normalize sensor readings.

**Generated by:** Python training script
**Used in:** C firmware (hardcoded values)

### 2. **fire_detection.onnx**
**Location:** `03_Model_Training/trained_models/` → Copy to `04_Model_Deployment/`

**Why Critical:** This is your trained AI model that STM32Cube.AI converts to C code.

**Generated by:** Python training script (XGBoost → ONNX)
**Used in:** STM32CubeMX import

### 3. **model_metadata.json**
**Location:** `03_Model_Training/trained_models/`

**Why Critical:** Contains accuracy, precision, recall for your final report (DR-05, DR-06 validation).

**Generated by:** Python training script
**Used in:** Final report, performance verification

### 4. **fire_detection_app.c**
**Location:** `05_Firmware/Core/Src/`

**Why Critical:** This is where you integrate the AI model with your sensor reading code.

**Generated by:** You write this (using template from guide)
**Used in:** Firmware build
